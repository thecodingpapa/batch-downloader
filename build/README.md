# Build Resources

Place your app icons here:

- `icon.png` — 512x512 PNG (required for all platforms)
- `icon.icns` — macOS icon (auto-generated from PNG by electron-builder)
- `icon.ico` — Windows icon (auto-generated from PNG by electron-builder)

## Generate from PNG

If you only have a `icon.png`, electron-builder will automatically convert it to `.icns` and `.ico` formats during the build process. Just make sure the PNG is at least 512x512 pixels.
